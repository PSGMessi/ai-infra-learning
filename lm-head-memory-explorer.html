公式与口径

标准路径峰值采用“显式 Logits 与 dLogits 可能同时活跃”的上界模型；实际 PyTorch、Megatron、Triton 或厂商 Kernel 可能通过原地覆盖、Buffer 复用、重计算和 Fusion 改变峰值。优化验收应同时使用 max_memory_allocated、memory snapshot 与 Nsight Systems/Compute。
所有数值为解析估算。CCE-like 的计算量按“Forward 后在 Backward 重算 Logits”的保守上界计算；稀疏梯度过滤带来的实际 FLOPs 降低未计入。Vocabulary Parallel 通信量按 Ring AllReduce 近似每 Rank 链路字节估算。
